# LectureFlow 更新记录

## 0.2.0 / build 3 — 2026-10-13

- 双语笔记随课堂递推累计：连接定义、解释、例子、推导和结论，保留前文主线；有上下文依据时修复明显断句与术语，成品直接呈现课程内容，不逐句叙述“新片段 / 推断 / 听不清”。无法恢复的细节只保留有依据的主题，不编造数字、人名、公式或事实。原始转写和原音保留供核对。
- 累计梳理增加中英思维导图：课程根节点连接主题和子节点，可拖动、缩放、回到课程中心、点击查看完整双语内容，并用“全屏”打开。连续生成时导图随课程主线更新。
- 新增“中文课 / 英文课”选择，使用多语 `base`。安装包内置并校验从官方 Whisper `base` 权重导出的 FLOAT32 编码器，修正原半精度编码器的数值溢出问题；其余 Core ML 组件及 tokenizer 首次准备仍需联网。旧 `tiny.en` 缓存保留。
- 低音量仅在送入 ASR 前做受限增益处理，原始 WAV 不变。每个 8 秒区间读取前后各最多 4 秒上下文，只提交当前区间的文字；异常时间戳不消耗待处理原音，可用“补转写原音”重试。
- 暂停保存后可对旧课程点“梳理整堂课”，生成累计梳理和导图，无需重新录音；保留过程笔记、人工编辑与原音。重建失败保留已有梳理。
- 修复非零温度解码重试的概率采样，增加音频窗口、增益、保存及解码回归检查。

已完成的验证包括音频核心检查、课程存储与模拟 HTTP 笔记请求检查、模拟器导图交互和中文语言选择重启保留检查。FLOAT32 编码器在 [macOS 诊断 CI 38352403251](https://github.com/yufeizheng314-png/LectureFlow/actions/runs/38352403251) 中完成中 / 英文 × 清晰 / 低音量四组合成语音的真实本机推理；低音量输入使用生产增益和 PCM 处理，原 WAV 保持不变。这些结果不等同真实教师录音、iPad 性能或真实云端 AI 笔记质量通过。

目标发布标记为 `v0.2.0-unsigned.1`，目标 IPA 为 `LectureFlow-0.2.0-build3-unsigned.ipa`。最终交付以完整构建、`IPA-VERIFICATION.json` 和 `SHA256SUMS.txt` 校验完成的文件为准；本次真机验收仍待完成。iPad Air M2 的模型准备、速度、质量、内存、电量、教师真实低声、真实 DeepSeek 笔记 / 导图和 90 分钟录音可靠性按验收清单实测。

bundle ID 保持 `com.yufeizheng.lectureflow`。先逐课导出笔记和全部原始 WAV，确认备份可打开，再用原 Apple 签名账号覆盖安装，不先卸载。升级后核对旧课程、编辑、原音和已有 DeepSeek / Keychain 设置。

语言选择和导图不要求另申请 API Key，已有 DeepSeek 配置继续使用。GPT / ChatGPT Pro 免 API Key 登录仍为后续工作，本版未接入；云笔记使用现有 HTTPS 服务、模型和个人 Key。

## 0.1.1 / build 2 — 2026-10-13

- AI 双语笔记结合已有课程内容累计梳理主题与关联，减少对每个新句子分别解释造成的割裂。
- 将连续的短转写片段合并后整理笔记，在有限上下文内保持课程连贯性。
- 已有课程可重新整理笔记，无需重新录制课堂原音。
- bundle ID 保持 `com.yufeizheng.lectureflow`，使用原签名账号覆盖安装后核对已有课程与录音。

本轮未加入 GPT / ChatGPT 订阅登录；云笔记继续使用设置中的 HTTPS 服务、模型名和个人 API Key。
英文识别模型仍为本机 `tiny.en`。笔记上下文改进不能还原错误识别的原文，内容不清楚时仍需回听原音、人工核对。

新版发布标记为 `v0.1.1-unsigned.1`，交付 IPA 为 `LectureFlow-0.1.1-build2-unsigned.ipa`。
旧版 `v0.1.0-unsigned.1` 保留；构建校验与真机验收结果分别记录。
