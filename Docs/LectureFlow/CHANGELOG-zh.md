# LectureFlow 更新记录

## 0.2.0 / build 3 — 2026-10-13（待构建与真机验收）

- 累计双语笔记增加思维导图：以课程为中心连接主题和子节点，可拖动、缩放、查看完整节点文字，并在全屏打开。
- 新增课堂语言选择，可按中文或英文课堂进行本地转写。默认识别模型改为多语 `base`，不使用英文专用 `base.en`；旧 `tiny.en` 缓存保留，`base` 首次仍需联网下载与准备。
- 低音量转写仅对 ASR 输入做受限幅度归一化，原始 WAV 保留不变。每个 8 秒转写区间最多使用前 4 秒上下文，提交属于当前区间的文本，边界重复、漏字与尾句仍需实测。
- 双语笔记利用前后文串联定义、例子和推导，合理补全连贯表达，成品不逐句叙述推断过程；原始转写保持可追溯，不编造数字、人名、公式或事实。
- 已有课程可重建累计梳理和导图；保留历史过程笔记、人工编辑与原音。语言选择和导图不要求另申请 API Key，现有 DeepSeek 配置继续使用。
- bundle ID 保持 `com.yufeizheng.lectureflow`。升级前先逐课导出笔记和原音备份，再用原签名账号覆盖安装，不先卸载应用；升级后核对旧课程和设置。

计划发布标记为 `v0.2.0-unsigned.1`，交付 IPA 为 `LectureFlow-0.2.0-build3-unsigned.ipa`。
本轮 CI 构建、IPA 校验和真机验收尚未完成；未宣称 `base` 在 iPad Air M2 上的识别质量、速度、续航或 90 分钟录音已达标。
GPT / ChatGPT Pro 免 API Key 登录仍为后续工作，本版未接入；云笔记仍使用已有 HTTPS 服务、模型和个人 Key。

## 0.1.1 / build 2 — 2026-10-13

- AI 双语笔记结合已有课程内容累计梳理主题与关联，减少对每个新句子分别解释造成的割裂。
- 将连续的短转写片段合并后整理笔记，在有限上下文内保持课程连贯性。
- 已有课程可重新整理笔记，无需重新录制课堂原音。
- bundle ID 保持 `com.yufeizheng.lectureflow`，使用原签名账号覆盖安装后核对已有课程与录音。

本轮未加入 GPT / ChatGPT 订阅登录；云笔记继续使用设置中的 HTTPS 服务、模型名和个人 API Key。
英文识别模型仍为本机 `tiny.en`。笔记上下文改进不能还原错误识别的原文，内容不清楚时仍需回听原音、人工核对。

新版发布标记为 `v0.1.1-unsigned.1`，交付 IPA 为 `LectureFlow-0.1.1-build2-unsigned.ipa`。
旧版 `v0.1.0-unsigned.1` 保留；构建校验与真机验收结果分别记录。
