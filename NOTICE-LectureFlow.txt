LectureFlow 0.1.1

This is an independently modified application based on the existing WhisperAX
example in argmaxinc/argmax-oss-swift, not an official Argmax product.
Upstream base commit: 9f99b5cb6a907730543823ad271b82532782a899.
Actual GitHub fork: https://github.com/yufeizheng314-png/LectureFlow
Upstream: https://github.com/argmaxinc/argmax-oss-swift

Changes made in 2026: iPad lecture recording and durable storage, bounded local
English transcription, optional incremental cloud bilingual notes, editing and
export UI, separate LectureFlow name/icon, and an unsigned iPad build workflow.
These additions are distributed under the repository's MIT License.

The original LICENSE and NOTICES are retained unchanged. NOTICES includes the
Apache-2.0 license and copyright attribution for the swift-transformers-derived
code already incorporated by upstream. Both complete texts are included in the
application and release package as LectureFlow-Licenses.txt.

The audio capture lifecycle also adapts the MIT-licensed VivaDicta implementation
by Anton Novoselov, commit d9bdb028f06bf448051e6e244291eb98ae9d9279.
Its full copyright/license and exact source references are retained in
Examples/WhisperAX/WhisperAX/LectureFlow/LectureFlowAudio-LICENSE.txt and included
in LectureFlow-Licenses.txt in the app bundle and release package.

The tiny.en Core ML model is downloaded separately at runtime from
https://huggingface.co/argmaxinc/whisperkit-coreml . That model card declares MIT;
weights are not bundled in the IPA and their model card remains authoritative.
This build has not downloaded model weights or measured their device performance.
Cloud notes use only the user's configured service and may incur its charges.
